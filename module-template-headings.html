Authoring a UL Module

How to fill in the module template, what each problem type needs, and how to read what the checker tells you while you write.

This guide is for the heading-and-paragraph template — the one that runs straight down the page, where each page of the course is a Heading 3. If your template is a single two-column table instead, you want the table guide.
01 Quick start 02 How the document is built 03 The eight problem types 04 Reading the sidebar 05 The deep check 06 Common mistakes

01Quick start

Five minutes from opening your copy to your first check. Nothing here needs setting up — the checker travels with the document.

  1. Open your copy of the template

    You have your own copy. Anything you type stays in it, and nothing you do here touches anyone else's module.

  2. Open the checker

    In the menu bar: Fixatron500 → Check document. A sidebar opens on the right. The first time, Google asks you to authorise the script — that is the copy asking to read the document it lives in.

  3. Press Check now

    A fresh copy reports 99 placeholders and nothing else. That is correct, and it is the number to expect: every one is a <<span like this>> waiting to be replaced. If you see anything other than placeholders on a copy you have not typed in, something is wrong — say so.

  4. Replace the placeholders, top to bottom

    Delete the whole << >> span, guillemets and all, and write your own words in its place. The text inside is an instruction to you, not text to keep.

    The one exception is Grading: any non-empty answer is marked correct. in the open-ended example — that line has no guillemets because it is meant to stay exactly as written.

  5. Watch the count come down

    The sidebar re-runs itself while it is open. The four counters at the top track the work: videos named, questions explained, answers marked, placeholders left. Finished, they read 2/2 · 9/9 · 9/9 and nothing is reported.

  6. Fix the errors, judge the warnings

    An error will break the conversion into the course. A warning is a judgement you are allowed to disagree with — click dismiss on any finding that is wrong for your module, and it stays dismissed.

The template's own examples are worked examples, not filler. Knowledge Checks A to F under the first video each show a different problem type, complete with the lines that type needs. Read the one you want, then write over it. Lecture 2 shows the plain shape — two checks and nothing else — which is what a lecture actually looks like once you are past the examples.

02How the document is built

Heading level is not styling here. It is the structure of the course, and the converter reads it literally.

LevelBecomesIn the template
Heading 1a sectionIntroduction · Lectures · Assignments · Conclusion
Heading 2a subsectiona lecture · an assignment · Module Overview
Heading 3a pagea video · a knowledge check · a problem · Summary
Heading 4a header inside that pageOverview · Learning Objectives · Key Takeaways

Heading 3 is the one that matters most. It makes a page of its own. Heading 4 makes a header inside the page above it. Give a problem a Heading 4 by mistake and it stops being its own page — it becomes a paragraph inside whatever came before, and no one finds out until the module is converted.

What a lecture holds, in order

Heading 3<<Video 1 Name>>

Heading 3Summary

Three rules the checker enforces about names

  • A knowledge check repeats its video's name. Knowledge Check A: Membrane Receptors sits under the video called Membrane Receptors. Rename the video and you must rename its checks.
  • Letters run in order. A, then B, then C, under each video. Skipping to C is reported.
  • An opening question goes before the first video. It asks what a learner already thinks, which only works before they have been told.

A video page

Video File Name: UB-CellBio_Components_01_Intro_v2
Transcript File Name: UB-CellBio_Components_01_Intro_v2_transcript

No file extension on the video name. A picture page uses File Name: and Alt Text: instead — and the alt text is required, because a learner using a screen reader gets nothing else.

03The eight problem types

Every problem opens with a Problem Type: line. It is the line that stops the checker guessing — without it, a multiple choice that forgot its (X) and an open-ended question look identical.

Check A

Multiple choice

One correct answer, chosen from a list. Round boxes, one tick.

Problem Type: multiple choice
Question: Which organelle produces most of the
ATP in a cell? Select the best answer.
Answer choices:
  (  ) the nucleus
  (X) the mitochondrion
  (  ) the ribosome
Explanation: The mitochondrion runs oxidative
phosphorylation… The nucleus is tempting because
it holds the DNA, but storing instructions is not
producing energy.

Must end with “Select the best answer.”

At most four options.

Check B

Checkbox

More than one correct answer. Square boxes, and every correct one marked.

Problem Type: checkbox
Question: Which of the following are purines?
Select all that apply.
Answer choices:
  [ ] cytosine
  [X] adenine
  [X] guanine
Explanation: Purines have a two-ring structure,
and adenine and guanine are the two in DNA.
Cytosine is a pyrimidine, with a single ring.

Square brackets [X], not (X) — and on every correct option, not just the first.

Check C

Dropdown

Choices sit inside the sentence. No separate list.

Problem Type: dropdown
Question: Use the dropdown options to complete
the statement. DNA replication happens during
the [&S/G1/M] phase of the cell cycle.
Explanation: S phase is when the genome is
copied, which is what replication means. G1 and M
fall either side of it.

The & marks the correct option inside the brackets.

Must contain “dropdown” or “Match the following”.

Check D

Numerical input

A number typed in. Needs a tolerance, or it is an error.

Problem Type: numerical input
Question: How many chromosomes are in a human
somatic cell? Enter your answer as a number.
Answer: 46
Accepted range: exact
Explanation: Somatic cells are diploid, so the
23 pairs come to 46 chromosomes in all.

Accepted range: is required — exact for a count, or ± 0.01, ± 2%, 3.1 – 3.2.

Check E

Short answer

A word or two, matched against what you list.

Problem Type: short answer
Question: Which phase separates the sister
chromatids?
Answer: anaphase
Also accept: late anaphase; anaphase A
Explanation: Anaphase is the phase in which the
spindle pulls the sister chromatids apart.

Semicolons separate alternatives — commas are read as part of one answer.

Check F

Open-ended auto-credit

Credit for answering at all. No right answer to explain.

Problem Type: open-ended auto-credit
Question: What would you target to fight
influenza? Any thoughtful answer will receive
credit.
Grading: any non-empty answer is marked correct.
Model answer: Entry, replication and release are
each reasonable targets to name.

No Explanation: — the model answer shows a good response instead, and nothing is being justified.

After Check F

Poll

Learners vote, then see how everyone voted. No right answer, and not graded.

Poll question: Which phase of the cell
cycle would you most like to see demonstrated
in a video?
Poll answers:
  • interphase
  • mitosis
  • cytokinesis
Feedback: Thanks for voting! The results show
which demonstration your classmates most want
to see.
Show results to learners: Yes
Submissions allowed: 1

Plain bullets — no ( ) on the answers, and no Problem Type: or Question: line. Written like a problem, the checker asks it for a marked answer and an explanation.

No Explanation: — Feedback: is what a learner sees after voting.

Built in Studio — the converter leaves a note in the poll's place with all of the above, and the poll is built from it by hand.

Not worked

Drag and drop

Learners sort items into named zones. Not worked in the template: write it as below, as the problem authoring guide shows.

Problem Type: drag and drop
Question: Place each statement under the type
of cell division it describes.
Zones:
  Zone 1: Mitosis
  Zone 2: Meiosis
Items (drag to the correct zone):
  Used for growth and tissue repair. → Zone 1
  Produces four haploid gametes. → Zone 2
Explanation: Mitosis copies the genome once and
splits it evenly into two identical cells, while
meiosis halves it to make gametes…

Each item names the zone it goes in, after an arrow: → Zone 1.

Built in Studio — the converter leaves a note in the problem's place with all of the above, and the problem is built from it by hand.

The checker does not check the zones and items, so it cannot tell you whether they are right. Keep the Problem Type: line: without it, bulleted items look like answers with none marked.

What every explanation needs

Two jobs in one place: why the keyed answer is right, and what makes a wrong option tempting. Below about fifteen words there is no room for both, and the checker says so.

Name options by what they say, never by where they sit. Options are shuffled when a learner sees them, so “the first option” points at whatever happens to be first for that person.

04Reading the sidebar

Sixty checks run locally, every few seconds while the sidebar is open. They cost nothing and never leave the document.

Check now
Re-runs everything immediately. It also runs on its own while the sidebar is open, so you rarely need this.
Highlight
Paints the flagged text yellow in the document, so you can find it without clicking each finding.
Clear highlights
Removes only the highlighting this tool added. Your own highlighting is left alone.
Clicking a finding
Jumps the cursor to the line it is about.
dismiss
Silences that one finding. It is keyed to what the finding says, so editing the sentence around it brings it back — deliberately, because the text it was a judgement about has changed.
mute rule
Silences a whole rule for this module. Use it when a rule does not apply to your subject at all.
Show what I read here
In the menu. Shows you the document as the checker sees it, which is the fastest way to work out why something was or was not found.

Dismissals live in the document, not in your account. The next person to open it sees the judgement already made, rather than making it again. They do not travel to a copy — a copy is new content.

05The deep check

A second tier that reads your explanations and judges whether they teach. It calls a model, so it costs money and runs only when you press the button.

Setting up your key

  1. Press Deep check

    The first time, it asks for an API key. Paste yours and press Save key.

  2. The key is yours alone

    It is stored against your Google account and this script — not in the document, not in the code, and not visible to anyone else who opens your module. It has a spend limit on it.

  3. Choose what to review

    You are shown the parts of the module and what each would cost in tokens before you commit. Reviewing one lecture is a fraction of the whole module, and each part is remembered separately — going back to a lecture you have already reviewed costs nothing.

The eight things it judges

CheckAsks
Explanations say whyDoes it give a reason, or just assert the answer?
Explanations add somethingDoes it restate the question in different words?
Explanations explainWould a learner who got it wrong now understand?
Explanations are sound errorDoes the reasoning actually support the keyed answer? This is the one filed as an error — a confidently wrong explanation teaches something false.
Options are completeHas an option been cut off mid-phrase?
Options are parallelDo the options match each other in form?
Prefer active voicePassive constructions that read as evasive.
Acronyms expand consistentlyIs the same acronym spelled out twice, or never?

Suggest an explanation

On any weak-explanation finding there is a Suggest an explanation button. It drafts a replacement you can copy, and it will append a note if it thinks your keyed answer might be wrong. It is a draft, not an answer — read it before you use it.

What it will not judge. Placeholders you have not filled in yet, and parts not written. The static checks already report those for nothing, and a model told to count them reports the same gap twice.

06Common mistakes

The ones that come up most, and what they look like when they do.

A problem at Heading 4
It stops being its own page and becomes a header inside the page above it. Nothing looks wrong in the document. Use Heading 3 for anything that should be a page.
Keeping the guillemets
Writing your question inside << >> leaves it marked as filler, so it is reported as unwritten and the rules that judge it stay quiet. Delete the marks with the instruction.
A checkbox with one tick
Round boxes and a single (X) is a multiple choice wearing a checkbox label. Nothing reports it, because a single answer is technically legal — but it is not what you meant.
Alternatives separated by commas
Answer: anaphase, late anaphase is read as one answer nobody will ever type. Use Also accept: with semicolons.
An explanation of one short sentence
Under about fifteen words there is no room to say why the answer is right and why a wrong option attracts. A well-built single sentence that does both passes.
Naming an option by position
“The first option is wrong because…” — options are shuffled per learner. Name the option by what it says.
Renaming a video, not its checks
A knowledge check takes its video's name. Nothing reports the mismatch, so it is worth a second look after any rename.
Typing your own numbering
1. 2. 3. typed by hand becomes literal text after conversion. Use the document's list buttons.

If the checker says something you think is wrong, it may well be. Dismiss it and carry on — then say so, because a rule that misfires on a real module is a rule worth fixing rather than working around.
