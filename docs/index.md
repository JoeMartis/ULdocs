# Module Author Guides

Everything you need to author course content that passes QA — how to write it,
how to enter each problem type, and how the automated checks judge your work.

## Writing your module

The template you were given, and the standards that apply to what you put in it.

- **[Authoring a UL Module in a Flat File](module-template-headings.html)** — The heading-and-paragraph template: how the document is built, what each problem type needs, and how to read the sidebar.
- **[Authoring a UL Module in Tables](module-template-tables.html)** — The two-column table template, where each row is a page. Same problem types, different document shape.
- **[Problem Templates](problem-authoring-guide.html)** — How to author each problem type, with worked examples and what makes a strong explanation. The same guidance is inside the template itself.
- **[Content Authoring Guide](content-authoring-guide.html)** — General writing, formatting, terminology, and page-structure rules for course content.
- **[Accessible Math & Science Markup](math-markup.html)** — How to write math and science notation so screen readers read it correctly.
- **[Attempts Policy](attempts-policy.html)** — How many attempts each problem type gets in knowledge checks and assignments.

## What gets checked

Two different tools, at two different stages. Fixatron500 reads your document
while you write it; the QA pass runs later, on content already in Studio. They
have separate rule catalogues.

- **[What the Checker Checks](checker-rules.html)** — All 60 checks the sidebar runs in the document as you write, plus the 8 in the deep check.
- **[Rule Reference](rule-reference.html)** — The full list of automated checks that run on content in Studio, with what each one looks for.

## Tools

Both open in a new tab. The Slide Description Writer has a
[full manual](https://claude.ai/code/artifact/cd59ab2f-215c-41a9-926d-45d878cb7481).

- **[Explanation Checker](https://joemartis.github.io/Explain2Me/)** (external site) — Paste an explanation and get instant feedback against the quality criteria before you submit.
- **[Slide Description Writer](https://joemartis.github.io/DescribeMe/)** (external site) — Turn slides or lecture-video frames into screen-reader-ready descriptions with MathML, ready to paste into your module.
