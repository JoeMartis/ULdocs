What the Checker Checks

Every check the sidebar runs on your module, what each one wants, and which ones you can safely ignore.

As you write
60 checks
Errors
15
Warnings

Deep check
8 on demand

Sixty checks run inside your document every few seconds while the sidebar is open. They cost nothing, need no setup, and nothing leaves the document. Eight more read your explanations properly, but those call a model — they cost money and run only when you press Deep check.

This list applies to both templates. The checks do not care whether your module is headings down a page or rows in a table.

Not the same thing as the Rule Reference. This page is Fixatron500, which reads your template in Google Docs while you write it. The Rule Reference is the automated QA pass that runs later, on content already in Studio. Two tools, two catalogues — the short codes tell them apart, and quoting one is the fastest way to say which check you mean.

Something here will break or mislead once the module is converted into the course. Fifteen of the sixty.

Judge these

A judgement you are allowed to disagree with. Click dismiss on any that is wrong for your module and it stays dismissed.

Questions

24 11 errors

The largest group by far, and the one that decides whether a problem works at all. Eleven of these are errors.

error

Questions have an explanation

The explanation is still the template's placeholder. Replace it with an "Explanation:" line saying why the correct answer is correct.

kc-explanation-present
error

Questions have a stem

No question text. The question stem belongs at the first list level, above the choices.

kc-stem-present
error

Questions mark a correct answer

No correct answer marked. Mark the correct choice with "(X)", or every correct one with "[X]" if more than one applies.

kc-correct-answer
error

Dropdowns mark one correct option

A dropdown has no correct option marked with "&".

kc-dropdown-answer
error

No duplicate choices

A choice repeats another word for word.

problem-duplicate-choices
error

No empty choices

A choice is empty.

problem-empty-choice
error

Choice questions offer alternatives

There is only one choice. A choice question needs at least two.

problem-single-choice
error

Questions match their declared type

What is written does not match the declared type — 2 choices are marked correct. Mark one, or change the type to checkbox.

problem-type-mismatch
error

Typed answers give the answer

No "Correct answer:" line. A numerical input has no options to mark, so the answer has to be written out.

problem-answer-present
error

Numerical answers are numbers

The correct answer is not a number. A numerical problem is graded by comparing numbers, so write the value alone — no units and no words.

problem-numerical-answer
error

Numerical answers give an accepted range

No accepted range. Give the tolerance a correct answer may fall within — "± 0.01", "± 2%", "3.1 – 3.2" — or write "exact" if the value is a count. The range is invisible on the page, so a missing one shows up as correct answers being marked wrong.

problem-numerical-range
warning

Explanations are not questions

The explanation ends in a question mark — it should explain the answer, not ask another question.

kc-explanation-not-question
warning

Choice questions are not overlong

There are more than four choices. The guide keeps a problem to 4 or fewer — split the question rather than lengthening the list.

problem-too-many-options
warning

Multiple choice says "Select the best answer"

Single-answer question is missing the prompt "Select the best answer."

prompts-mc-select-best-answer
warning

Checkbox says "Select all that apply"

Multiple-answer question is missing the prompt "Select all that apply."

prompts-checkbox-select-all
warning

Dropdowns explain themselves

Dropdown question does not tell the learner to use the dropdowns — e.g. "Use the dropdown options to complete the following statements."

prompts-dropdown-instruction
warning

"Type:" names a question type

The declared type is not one the tool knows. Use one of: multiple choice, checkbox, dropdown, numerical input, short answer, open-ended auto-credit, drag and drop. Until this line is read the question is classified by guessing from its markers.

problem-type-unknown
warning

Accepted answers are distinct

An accepted answer repeats one already listed. Matching ignores case, so this variant grades nothing the first one does not.

problem-accepted-answers
warning

Options are not hand-lettered

The options carry hand-typed letters. Options may be shuffled when they are displayed, so a label ends up against the wrong option — delete them.

problem-option-labels
warning

Explanations do more than assert the answer

The explanation is too short. Say why the answer is right and what makes a wrong option tempting — one that only states the answer leaves a learner where they were.

kc-explanation-substantive
warning

Explanations name options by content

The explanation names an option by its position. Options are shuffled when they are displayed, so name the option by what it says instead.

kc-explanation-positional
warning

Numerical input says how to enter the answer

Numerical input does not say how to enter the answer — e.g. "Enter your answer as a whole number in the space provided."

prompts-numerical-instruction
warning

Open-ended problems carry the auto-credit sentence

Open-ended problem does not say that answering earns credit. Add "Any thoughtful answer will receive credit." to the question, so it does not read as graded.

prompts-open-ended-phrase
warning

Knowledge Checks are lettered in sequence

A knowledge-check letter is out of sequence. Letters should run A, B, C without gaps.

kc-sequential-lettering

The deep check

8 1 error

These read what you wrote and judge whether it teaches — which no amount of pattern-matching can do. They run only when you press the button, on the part of the module you choose, against your own API key.

Not judged: placeholders you have not filled in, and parts not written yet. The sixty checks above already report those for nothing.

error

Explanations are sound

The reasoning does not support the answer you keyed — it argues for a different option, or states something false. The only one filed as an error: a thin explanation leaves a learner where they were, but a confident wrong one teaches them something untrue.

ai-explanation-unsound
warning

Explanations say why

The explanation asserts the answer is correct and gives no reason, so a learner who got it wrong has nothing to reason from next time.

ai-explanation-why
warning

Explanations add something

The explanation restates the question, or repeats the wording of the correct option, adding nothing the learner did not already have in front of them.

ai-explanation-restates
warning

Explanations explain

What is in the explanation is not an explanation at all — a note left for yourself, or words that carry no meaning.

ai-explanation-quality
warning

Options are complete

An answer choice is cut off mid-thought, or is obviously missing its ending.

ai-truncated-option
warning

Options are parallel

The choices do not match each other in form — fragments mixed with full sentences, or inconsistent capitalisation and trailing punctuation.

ai-option-format
warning

Prefer active voice

A sentence is passive where the active would be clearer. Only raised where there is an identifiable actor and the rewrite is obvious.

ai-active-voice
warning

Acronyms expand consistently

The same acronym is spelled out differently in different places.

ai-acronym-consistency

Two ways to silence a check. Dismiss hides one finding, and is keyed to what that finding says — so editing the sentence around it brings it back, deliberately, because the text it was a judgement about has changed. Mute rule hides a whole rule for the module, for when a rule does not apply to your subject at all. Both live in the document, so the next person to open it sees the judgement already made.

If a check is wrong, say so. These are rules written by people, and a rule that misfires on a real module is worth fixing rather than working around. Dismiss it, carry on, and tell us which one.

Rule names are the short codes under each entry — quoting one (problem-numerical-range, say) is the fastest way to be precise about which check you mean.
